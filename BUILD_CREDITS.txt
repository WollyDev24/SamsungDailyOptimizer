Vertex 1.4.2 — One UI 9 / ZRAM-safe community build
Build author / maintainer: Lernik
Original Vertex project: Wolly (WollyDev24)
Original source: https://github.com/WollyDev24/Vertex

This is an unofficial modified distribution of Vertex 1.4.2.
It preserves the original project's attribution and LICENSE.

Changes relative to upstream Vertex 1.4.2:
- Guard ZRAM management against resetting/reinitializing active zram0,
  including the WebUI's live ZRAM algorithm selection.
- Correct the daemon schedule check to prevent premature maintenance.
- Add launch diagnostics to support troubleshooting Android Rescue Party.

NOTE: These fixes are based on analysis of an S23 Ultra crash report.
They are not a guarantee that all device/kernel combinations are stable.
Potential temporary-root loss or reboot is still possible on unsupported
configurations. Test carefully and keep backups.

Original project and its respective contributors retain credit for upstream
functionality. The new changes are identified above.
